# TimeZone

The timezone for the reporting data. Use 'ORTZ' for Organization Time Zone or 'UTC' for Coordinated Universal Time. Default is UTC.

## Example Usage

```java
import com.airbyte.api.models.shared.TimeZone;

TimeZone value = TimeZone.ORTZ;
```


## Values

| Name   | Value  |
| ------ | ------ |
| `ORTZ` | ORTZ   |
| `UTC`  | UTC    |
