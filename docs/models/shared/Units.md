# Units

Units of measurement. standard, metric and imperial units are available. If you do not use the units parameter, standard units will be applied by default.

## Example Usage

```java
import com.airbyte.api.models.shared.Units;

Units value = Units.STANDARD;
```


## Values

| Name       | Value      |
| ---------- | ---------- |
| `STANDARD` | standard   |
| `METRIC`   | metric     |
| `IMPERIAL` | imperial   |
