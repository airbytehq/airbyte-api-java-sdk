# SourceZohoExpenseDataCenter

The domain suffix for the Zoho Expense API based on your data center location (e.g., 'com', 'eu', 'in', etc.)

## Example Usage

```java
import com.airbyte.api.models.shared.SourceZohoExpenseDataCenter;

SourceZohoExpenseDataCenter value = SourceZohoExpenseDataCenter.COM;
```
