# EncryptionAlgorithm

This parameter defines the database encryption algorithm.

## Example Usage

```java
import com.airbyte.api.models.shared.EncryptionAlgorithm;

EncryptionAlgorithm value = EncryptionAlgorithm.AES256;
```


## Values

| Name           | Value          |
| -------------- | -------------- |
| `AES256`       | AES256         |
| `RC456`        | RC4_56         |
| `THREE_DES168` | 3DES168        |
