# MarketNewsCategory

This parameter can be 1 of the following values general, forex, crypto, merger.

## Example Usage

```java
import com.airbyte.api.models.shared.MarketNewsCategory;

MarketNewsCategory value = MarketNewsCategory.GENERAL;
```


## Values

| Name      | Value     |
| --------- | --------- |
| `GENERAL` | general   |
| `FOREX`   | forex     |
| `CRYPTO`  | crypto    |
| `MERGER`  | merger    |
