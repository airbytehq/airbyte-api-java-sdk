# PermissionScope

Scope of a single permission, e.g. workspace, organization

## Example Usage

```java
import com.airbyte.api.models.shared.PermissionScope;

PermissionScope value = PermissionScope.WORKSPACE;
```


## Values

| Name           | Value          |
| -------------- | -------------- |
| `WORKSPACE`    | workspace      |
| `ORGANIZATION` | organization   |
| `NONE`         | none           |
