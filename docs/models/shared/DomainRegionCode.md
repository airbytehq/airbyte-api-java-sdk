# DomainRegionCode

Domain region code. 'EU' or 'US' are possible values. The default is 'US'.

## Example Usage

```java
import com.airbyte.api.models.shared.DomainRegionCode;

DomainRegionCode value = DomainRegionCode.US;
```

| `US`  | US    |
