# OutputSize

Whether to return full or compact data (the last 100 data points).


## Example Usage

```java
import com.airbyte.api.models.shared.OutputSize;

OutputSize value = OutputSize.COMPACT;
```


## Values

| Name      | Value     |
| --------- | --------- |
| `COMPACT` | compact   |
| `FULL`    | full      |
