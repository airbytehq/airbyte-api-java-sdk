# SourceKlarnaRegion

Base url region (For playground eu https://docs.klarna.com/klarna-payments/api/payments-api/#tag/API-URLs). Supported 'eu', 'na', 'oc'

## Example Usage

```java
import com.airbyte.api.models.shared.SourceKlarnaRegion;

SourceKlarnaRegion value = SourceKlarnaRegion.EU;
```
