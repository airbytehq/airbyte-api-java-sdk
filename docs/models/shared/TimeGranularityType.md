# TimeGranularityType

Granularity of the statistics for metrics per time period. Must be either "DAY" or "MONTH"

## Example Usage

```java
import com.airbyte.api.models.shared.TimeGranularityType;

TimeGranularityType value = TimeGranularityType.DAY;
```


## Values

| Name    | Value   |
| ------- | ------- |
| `DAY`   | DAY     |
| `MONTH` | MONTH   |
