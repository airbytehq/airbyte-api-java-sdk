# SortBy

The order to sort the articles in. Possible options: relevancy,
popularity, publishedAt.


## Example Usage

```java
import com.airbyte.api.models.shared.SortBy;

SortBy value = SortBy.RELEVANCY;
```


## Values

| Name           | Value          |
| -------------- | -------------- |
| `RELEVANCY`    | relevancy      |
| `POPULARITY`   | popularity     |
| `PUBLISHED_AT` | publishedAt    |
