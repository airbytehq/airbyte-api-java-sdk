# HashingMethod

The hashing algorithm to use.

## Example Usage

```java
import com.airbyte.api.models.shared.HashingMethod;

HashingMethod value = HashingMethod.MD2;
```


## Values

| Name     | Value    |
| -------- | -------- |
| `MD2`    | MD2      |
| `MD5`    | MD5      |
| `SHA1`   | SHA-1    |
| `SHA224` | SHA-224  |
| `SHA256` | SHA-256  |
| `SHA384` | SHA-384  |
| `SHA512` | SHA-512  |
