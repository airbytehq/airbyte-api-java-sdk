# SourcePhylloEnvironment

The environment for the API (e.g., 'api.sandbox', 'api.staging', 'api')

## Example Usage

```java
import com.airbyte.api.models.shared.SourcePhylloEnvironment;

SourcePhylloEnvironment value = SourcePhylloEnvironment.API_SANDBOX;
```


## Values

| Name          | Value         |
| ------------- | ------------- |
| `API_SANDBOX` | api.sandbox   |
| `API_STAGING` | api.staging   |
